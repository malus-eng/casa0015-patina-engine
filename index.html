DIGITAL PATINA SENSOR

A Connected Environments application bridging the gap between physical material degradation and digital IoT tracking. Designed for 950 silver and Amekaji jewelry collectors.

View Project on GitHub

The Problem We Solve

Traditional collectors have no way to digitally measure how their specific physical environment affects the aging and sulfation of their jewelry. This app continuously intercepts live atmospheric data in London to calculate and visualize the real-time patina accumulation.

Core Features

Live IoT Integration

Silently fetches Humidity and SO2 data via OpenWeather API using background automation.

Physics Algorithm

Calculates realistic oxidation increments based on time exposure and air quality metrics.

Dynamic UI & Cloud

Visual badges transition from silver to black, with historical growth curves backed by Firestore.
