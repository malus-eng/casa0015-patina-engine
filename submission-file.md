# Introduction to Application

Digital Patina is a Connected Environments mobile application built with Flutter, designed to act as a digital inventory and oxidation tracker for 950 silver jewelry. Unlike traditional static apps, it continuously intercepts live atmospheric data (specifically Humidity and SO2 levels) from the physical environment in London using external APIs. The application processes these environmental variables through a custom physics-based algorithm to calculate and simulate the highly realistic, slow-paced sulfation (patina) process of physical silver over time. Key features include a background automation engine that syncs environmental data hourly, an interactive UI that visually degrades from bright silver to oxidized black based on accumulated data, and data visualization charts mapping the item's historical growth curve retrieved from Firebase Firestore. This app bridges the gap between digital data tracking and physical material degradation.
